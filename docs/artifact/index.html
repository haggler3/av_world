World Model Upgrades

A survey of world-model research produced ten ideas, rated for return against effort. Seven were built, three were skipped as rated. Each result below comes from a run in the repository, with its confidence interval, its test, and where it did not work.

IDEA 1

Common random numbers keyed to the vehicle

works, modestly

Most questions here are differences between two worlds in a rare outcome. Pairing the worlds with the same dice makes the difference far less noisy, but only if each driver keeps its dice in both worlds.

Var(Δ̂) = (σ₀² + σ₁² − 2ρ·σ₀σ₁) / n          R = (σ₀² + σ₁²) / Var(Y₁ − Y₀) = 1 / (1 − ρ)   when σ₀ = σ₁

before   u = uniform(key, (8N, …))            one number per array slot; a new car takes the first free slot
now      uid = tick·24 + attempt              the spawn attempt that created the car, assigned at the attempt
         U(i,t,s) = 2⁻²⁴ · ⌊ h( h(uid·c₁ + s·c₂ + 1) ⊕ seed_t ) / 2⁸ ⌋        h = lowbias32; seed_t depends on the key chain only

monotone thinning     event fires iff U(i,t,s) < λ·Δt      {U < λ₀Δt} ⊆ {U < λ₁Δt}  for λ₀ ≤ λ₁

With slot-indexed dice, the first crash or wreck in one world reshuffles which car sits in which slot, and the two worlds stop sharing dice. With identity-keyed dice, raising a rate only adds events, so two worlds differ by the fewest possible. Each world keeps its exact marginal law.

IDEA 2

Pricing the model’s mistakes

works, with the right signal

A planner pointed at a learned model finds the plans where the model is most wrong in its favour. A penalty on distance from the training data removes most of that. A penalty on ensemble disagreement removes none.

winner’s curse     Ĵ(a) = J(a) + ε(a),  E ε(a) = 0 for each fixed a   ⇒   E ε(a*) > 0  for  a* = argmax Ĵ

naive      J = Σ γᵗ rₜ
MOPO       J = Σ γᵗ ( rₜ − λ·sₜ )                          J(π) ≥ Ĵ(π) − λ·E[u]  when u bounds the error
WIMLE      J = Σ γᵗ wₜ rₜ ,   wₜ = exp( −Σ_{j≤t} s_j / τ )
truncate   J = Σ_{t<T*} γᵗ rₜ ,   T* = min { t : sₜ > s_max }

signal 1   sₜ = ensemble SD of the predicted change
signal 2   sₜ = max { 0, d(xₜ, R) / q − 1 }      xₜ = (oₜ, uₜ), R = 2,000 training inputs, q = median held-out nearest-neighbour distance

A model is fitted to 20,000 transitions of a cautious controller in the corridor environment. A cross-entropy planner picks 2 s plans from 256 real states for a greedy task, and the plans run in the real environment with the safety shield off. Reward is the same function of the observation on both sides, so imagined minus real is model error alone.

Why the ensemble fails. The three members agree almost everywhere: mean spread 0.025 on the planner’s plans against 0.026 on the training data. A model can predict well and all its copies can be wrong together. Limits: one fitted model, one task, open-loop 2 s plans, and a data-poor regime chosen so that exploitation exists.

IDEAS 3 AND 5

An agent-token model, and drivers learned from real logs

small gain beyond the leader

A transformer over the agent and its neighbours, trained on 400 Argoverse 2 scenes, predicts real driving better than IDM over 3 s. What helps is the leader. Eight neighbours do worse than one.

Idea 5: the leader model as the simulator’s human driver

A human on a car-following gap takes its acceleration from the leader model; stop lines, parked cars and courtesy gaps stay IDM. Scored with the statistics measured on Argoverse 2, 3 replicates of 60 s in Oakland.

IDEA 4

Looking back, and training on the model’s own rollouts

mixed

The rollout loss removes 73 % of the 3 s speed error and makes the gap error larger. Use it for speed, not for gaps.

L = Σ_{k<K} γᵏ · ℓ( ô_{t+k+1}, o_{t+k+1} ) / Σ_{k<K} γᵏ          ô_{t+k+1} = f( ô_{t+k}, …, ô_{t+k−H+1} ; u_{t+k}, … )

one-step training never sees its own errors; a linearised error obeys  e_{k+1} ≈ A·e_k + ε  and grows like ‖A‖ᵏ
(H, K) = (1, 1) is the old model, so {1, 3} × {1, 10} is an ablation on the same data

Cause, as far as it is known. A Huber loss on all continuous features, weighted equally, trades the gap (hard to predict from the policy’s 22 features) for the speed. Per-feature weights were not tried.

IDEAS 7 AND 8

A collapse guard, and a terminal value

one guard, one null

Idea 7: SIGReg

A joint-embedding model minimises ‖g(f(o), u) − f(o′)‖², which a constant f minimises perfectly. The regulariser pushes embeddings towards a standard Gaussian, tested on random projections.

EP(x) = N · ∫ | φ̂(t) − e^(−t²/2) |² e^(−t²/2) dt        φ̂(t) = (1/N) Σₙ e^(i t xₙ)        SIGReg(z) = E over unit w of EP( ⟨z, w⟩ )

for true Gaussian input  E[EP] = √(2π) − √(2π/3) ≈ 1.06  (not zero, and it does not grow with N);  constant or two-point input: 400 to 1,600

On the corridor environment’s 380 k transitions the embedding collapses without the term (spread 0.0001, prediction loss 0) and keeps a spread of 0.99 with it (left panel of the figure above). Linear probes are mixed: speed R² 0.95 without against 0.74 with, gap R² 0.44 against 0.81. It is a collapse guard, not an accuracy gain.
