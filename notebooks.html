Learn av_world in five short notebooks

Each one runs in a few minutes on a laptop CPU, or in Colab with no setup: the first cell clones the repository if it is not already there. They are committed executed, so you can read every number and figure on GitHub before running anything.

Start here · ~1 min on a laptop CPU

A five-minute tour

The whole repository in one sitting: many copies of a city in one compiled call, what it looks like, how many AVs it takes to halve crashes, and your own driver scored on AVBench.

  • av_world.make, reset, rollout
  • the city map with every vehicle
  • an AV-share miniature
  • a 15-line policy on AVBench

What an AV observes (28 named features), what a policy returns, what the reward is made of, and how to change it.

  • one step, one rollout, the transition dict

  • what the trained policy does with its inputs

Notebook 03 · ~4 min on a laptop CPU

Training with PPO

Multi-agent PPO with every AV driven by one policy: a short training run, learning curves against the full run, a fine-tune with your own reward, and both scored on AVBench.

  • avrl.xppo.train: behaviour cloning, then PPO
  • train_log.json curves
  • init= and reward= for fine-tuning
  • bench.evaluate against the leaderboard

Run them locally

From a clone of the repository:

pip install -e . jupyter
pip install pyvista     # for notebook 04
jupyter lab notebooks/

From the command line

The same things without a notebook:

python -m avrl.xppo --out results/my_run
av-world export-perception out \
    --scenario bus_dartout --area chicago
python examples/my_policy.py
av-world watch oakland
